# React JS

React learning projects using Vite. The main `react-course` app combines small exercises around components, props, forms, reducers, routing, browser storage, and API fetching.

## `react-course`

The source includes `UserList`, `AddUser`, and `Edit` components for a user CRUD-style flow, as well as examples for controlled inputs, `useReducer`, Suspense-based fetching, and a local-storage RGB color picker. Some experiments are kept commented in `src/App.jsx` so they can be enabled one at a time.

## Run

```bash
cd react-course
npm install
npm run dev
```

Other scripts are `npm run build`, `npm run lint`, and `npm run preview`.
