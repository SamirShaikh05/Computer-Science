# React course exercises

A Vite-based React learning app with examples for component composition, props, controlled forms, routing, reducers, Suspense-style data loading, local storage, and Bootstrap/Tailwind styling experiments.

The main files include `UserList`, `AddUser`, and `Edit` for a user workflow. `App.jsx` also keeps several standalone exercises commented out so they can be studied and enabled independently.

## Run

```bash
npm install
npm run dev
```

Use `npm run build` to create a production bundle, `npm run lint` to check the source, and `npm run preview` to serve the build locally.
