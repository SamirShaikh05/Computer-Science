# TypeScript

TypeScript language exercises plus a React/Vite practice app.

## Core exercises

`src/` covers arrays/enums, functions, generics, interfaces, objects, classes, type narrowing, unions, `any`, and HTTP requests with Axios. The small `src/index.ts` example prints a typed greeting.

## ReactTS

`ReactTS/` is a typed React UI with reusable `ChaiCard`, `ChaiList`, `Counter`, `OrderForms`, and `Card` components. It demonstrates typed props, a `Chai` model, event handlers, and a custom `useFetch` hook.

## Run

For the language exercises:

```bash
npm install
npm run dev
```

For the React app:

```bash
cd ReactTS
npm install
npm run dev
```

The React project also supports `npm run build`, `npm run lint`, and `npm run preview`.
